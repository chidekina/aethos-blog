## Editing rules that bit this session

🔴 **Never edit a `.sh` while it is running** — bash reads by byte offset and a
patch that shifts text resumes execution mid-token.

🔴 **Killing a mutation harness mid-run leaves the source MUTATED.** The
end-of-run restore cannot fire on a run that never reaches its end.
`fetch-news.mutate.sh` now traps `INT`/`TERM`; if you kill any other one, check
`git status` before doing anything else.

🔴 **`git checkout` changes what you are measuring.** A suite read 59 assertions
on `main` and 66 on the branch, and it looked like non-determinism. Two identical
runs were the control that caught it.
