# BLOCKING CONSTRAINTS — Read Before Anything Else

> Each was discovered through an actual failure this session, not predicted.

- [ ] CONSTRAINT: **In zsh, a parameter followed by a colon is a MODIFIER.**
      `git show "$ref:path/to/file"` silently returns something other than that
      file. It made a fix look absent from two branches that carried it, and I
      was one step from reporting the stack had lost it. Always brace:
      `git show "${ref}:path/to/file"`.

- [ ] CONSTRAINT: **A CI waiter keyed on anything but GitHub's own merge
      readiness reports a STALE GREEN.** Three versions failed: pinning the head
      raced `update-branch`; re-reading the head each poll still accepted the old
      head, because its gate was already `completed/success`. Poll
      `mergeStateStatus` — `CLEAN` encodes both up-to-date-with-base and
      checks-green. Cost was time, not safety: `strict: true` makes GitHub refuse
      a behind-or-ungreen merge outright.

- [ ] CONSTRAINT: **GitHub does NOT retarget a stacked PR when its base branch
      merges**, because `delete_branch_on_merge` is false here so the base still
      exists. #31 and #34 both still pointed at branches that no longer led
      anywhere. Read the base before every merge; never infer it.

- [ ] CONSTRAINT: **This repo merges by REBASE, so every stacked branch comes up
      DIRTY.** The same content arrives under different SHAs. Rebase the branch
      onto `main` — git drops the duplicates by patch-id — then re-run the full
      gate on the rebased result before pushing.

- [ ] CONSTRAINT: **A `CONTRACT.md` rule written outside the yaml fence is
      ignored in silence, exit 0.** A fourth way to be green for free, beyond the
      three the repo documents. My first forged control did exactly this and I
      nearly read it as the validator having no teeth. Forge inside the fence, in
      the shape the file actually uses.

- [ ] CONSTRAINT: **`node --check` does not resolve imports.** It passed a file
      importing a symbol that does not exist on that branch. Syntax check is not
      a link check — run the thing.

- [ ] CONSTRAINT: **A background task killed for memory is NOT a verdict.** Three
      waiters were stopped mid-run this session. "killed" means the instrument
      stopped, never that the thing being watched failed.

**Do not proceed until all seven boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---|---|---|---|
| zero from a blind reader | A grep returned 0 for text that was present; a reader looked up `missing.tokens`, a key that does not exist, and printed nothing on every `fail` | blocking | print a positive control beside every zero, in the SAME run |
| `re.S` on a single-line pattern | `^const X = .*$` under DOTALL ate the rest of the file and produced a 702-line "module" | advisory | flags are per-pattern; assert every extracted block is no longer than its own construct |
| suite capture merging stderr | An arm captured `2>&1` and so tested the merge rather than the `--json` contract it existed to assert | advisory | capture the channel the contract is about, and assert the other channel separately |
| fixture that is a true positive | Every greeting fixture was a real greeting, so 29/0 said nothing about the rule eating prose | blocking | every rule gets an arm asserting what must SURVIVE |
| mutation that misses its anchor | `M8` targeted a line my edit had moved | advisory | the harness must report ANCHOR MISSED, never run green against an intact file |
