- [ ] CONSTRAINT: **This shell has aliases that corrupt command substitution.**
      `cat` is `bat` and `ls` is `eza`. `BK=$(ls -1t …| head -1)` returned a
      directory, and the resulting `crontab -` wiped 40 lines of the operator's
      crontab down to 3. Restored from a backup taken seconds earlier.
      Mitigation: `command ls` / `command cat` inside substitutions, back up
      before any `crontab -` write, and verify the RESULT by reading it back.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---|---|---|---|
| Gate narrower than what it guards | Hit four times: `tsc` skipping `.astro` (6 of 9 files unchecked, reported 0 errors); a CONTRACT rule that blanked the template literal it was reading; a rule globbing published posts so publishing was a violation; a wrapper suite whose arms passed because no `node` happened to sit in `/usr/local/bin` | blocking | Forge a violation of a DIFFERENT variant than the one that motivated the rule, and require red. Green against correct code alone certifies nothing |
| Local green as evidence | `readFileSync().buffer` handed Satori the shared Buffer pool and broke only on Vercel; a hardcoded repo path worked only on this machine | blocking | Treat CI and the Vercel preview as the verdict. A build that passes here has not been tested on a different allocation history or filesystem layout |
| Exit code read as effect | `crontab -` returned 0 while destroying the file; the digest logged `DIGEST_OK … drafts written` having written zero files | blocking | Read the resulting state — `crontab -l`, `git ls-remote`, the built `dist/` — never `$?` |
| Zero without a control | A grep or probe returning nothing is indistinguishable from a blind instrument | advisory | Print a positive control beside every zero, in the same command |
